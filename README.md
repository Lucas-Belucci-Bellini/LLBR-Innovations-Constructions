## Como abrir localmente

Abra o arquivo `index.html` no navegador ou rode um servidor estatico simples:

```bash
python -m http.server 3000
```

Depois acesse `http://localhost:3000`.

## Deploy na Vercel

Este projeto está pronto para deploy como site estático na Vercel.

1. Importe o repositório `Lucas-Belucci-Bellini/LBR-Innovations-Constructions` na Vercel.
2. Mantenha o framework como `Other` ou `Static`.
3. Use a raiz do repositório como diretório do projeto.
4. Não é necessário configurar build command.

O arquivo `vercel.json` já define URLs limpas e cache para imagens em `assets/`.
